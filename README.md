# Savebili 文档

## 功能

- 通过 `/saveany <BV号或链接>` 或 `@机器人 <BV号或链接>` 下载 B 站视频并发送文件。
- 支持 B 站短链（b23.tv、bili2233.cn 等）自动解析，群聊中仅响应 @机器人 的消息。
- 支持扫码登录、手动添加 Cookie、多 Cookie 优先级管理。
- Web 管理页面提供扫码登录、Cookie 管理、配置修改。
- 配置修改后自动保存并生效。
- 模仿saveany任意下载的工作原理制作

## 使用方法

1. 在插件管理界面启用本插件。
2. 打开插件管理页面，进行扫码登录或手动添加 Cookie。
3. 在聊天中发送 `/saveany BV[号]`，或 @机器人 后发送 BV 号、视频链接、短链。
4. 机器人会自动解析并下载视频后发送。

## 配置项

- `download_dir`：视频下载保存目录。留空时使用插件数据目录下的 `downloads`；填写相对路径时也基于插件数据目录解析（不再跟随进程工作目录）。
- `max_size_mb`：允许下载的最大视频大小(MB)
- `quality`：默认画质代码

## 注意事项

- 请勿泄露 B 站 Cookie。
- 下载高清视频可能需要登录。
- 部分平台可能不支持视频消息。
- 禁止将视频二次分发，否则版主追责，概不负责！
